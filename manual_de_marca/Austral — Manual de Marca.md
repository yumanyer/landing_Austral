## Sistema tipográfico

Dos tipografías, un mismo propósito: **Die Grotesk** (sans · tech · datos) y **Lora** (serif · editorial).

### Die Grotesk

Aa Bb Cc Dd 0123456789

| Peso | Uso |
| --- | --- |
| Bold | Títulos y destacados |
| Medium | Subtítulos y elementos |
| Regular | Cuerpo de texto |
| Light | Textos secundarios y legales |

### Lora

Aa Bb Cc Dd 0123456789

| Peso | Uso |
| --- | --- |
| Regular | Textos institucionales, manifiestos, artículos |
| Medium | Énfasis editorial, subtítulos |
| Semibold | Titulares editoriales |

### Roles

| Rol | Tipografía |
| --- | --- |
| 01 Marca (logotipo, titulares de alto impacto) | Die Grotesk Semibold |
| 02 Datos / números (precios, balances, métricas, fechas) | Die Grotesk Medium / Semibold |
| 03 Texto editorial | Lora Regular |
| 04 Énfasis editorial | Lora Medium / Semibold |
| 05 UI / producto digital (navegación, botones, formularios) | Die Grotesk Regular / Medium |
