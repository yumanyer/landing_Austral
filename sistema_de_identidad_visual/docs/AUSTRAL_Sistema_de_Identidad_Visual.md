# AUSTRAL — Sistema de Identidad Visual

## 01. Identidad de marca

**Marca:** AUSTRAL

**Conceptos asociados:**
- Crecimiento
- Dirección
- Futuro

**Slogan:**

> AUSTRAL  
> IMPULSAMOS  
> LO QUE VIENE

---

# 02. Sistema de marca

## 2.1 Isotipo

El isotipo constituye el **símbolo principal de Austral**.

Su construcción combina una **A estilizada** con una **flecha ascendente**, representando visualmente:

- Crecimiento
- Dirección
- Movimiento
- Proyección hacia el futuro

El isotipo debe conservar siempre su construcción, proporciones y geometría originales.

## 2.2 Logotipo

El logotipo está compuesto exclusivamente por la palabra:

**AUSTRAL**

El logotipo utiliza **Die Grotesk Semibold**.

Su función es identificar verbalmente a la marca y mantener una presencia clara, geométrica y contemporánea.

## 2.3 Marca completa

La marca completa está formada por:

**Isotipo + Logotipo**

El isotipo se posiciona a la izquierda y el logotipo **AUSTRAL** a la derecha.

Esta composición constituye la versión principal de identificación de la marca.

---

# 03. Sistema tipográfico

Austral utiliza una combinación de dos familias tipográficas con funciones diferenciadas:

- **Lora** → letras, comunicación editorial y expresión de marca.
- **Die Grotesk** → números, caracteres, datos, interfaz y elementos funcionales.

La combinación busca generar un contraste entre una voz **editorial y humana** y una expresión **precisa, técnica y digital**.

## 3.1 Lora — Tipografía editorial

**Familia:** Lora  
**Clasificación:** Serif / Editorial

Lora se utiliza principalmente para textos compuestos por letras y para aquellos mensajes donde se busca una expresión más editorial, institucional y de marca.

### Pesos

| Peso | Uso |
|---|---|
| **Regular** | Cuerpo de texto y textos editoriales |
| **Medium** | Énfasis editorial |
| **Semibold** | Titulares y destacados |

### Usos principales

- Titulares editoriales
- Mensajes institucionales
- Manifiestos
- Claims
- Frases de marca
- Textos narrativos
- Subtítulos editoriales
- Mensajes de mayor énfasis

### Ejemplo

> Crecimiento que mira hacia adelante.

> Más que una plataforma, una visión de futuro.

---

## 3.2 Die Grotesk — Números y caracteres

**Familia:** Die Grotesk  
**Clasificación:** Sans / Tech / Datos

Die Grotesk se utiliza para números, datos, caracteres y elementos funcionales del sistema.

### Pesos

| Peso | Uso |
|---|---|
| **Regular** | Interfaz y elementos funcionales |
| **Medium** | Navegación, datos y elementos secundarios |
| **Semibold** | Datos destacados, CTAs y elementos de alta jerarquía |

### Usos principales

- Números
- Precios
- Porcentajes
- Métricas
- Fechas
- Datos financieros
- Códigos
- Caracteres especiales
- Navegación
- Botones
- Formularios
- Dashboards
- Aplicaciones digitales
- Labels y elementos de UI

### Ejemplos

```text
$ 125.430,50
+4,82%
BTC 0.08421
24h
```

## 3.3 Tipografía de marca

El **logotipo AUSTRAL** utiliza:

**Die Grotesk Semibold**

Esta aplicación es específica para la construcción de la marca y no debe confundirse con el uso editorial de Lora.

# 04. Jerarquía tipográfica

La jerarquía se construye combinando las dos familias según la naturaleza del contenido.

| Elemento | Tipografía | Peso |
|---|---|---|
| Logotipo | Die Grotesk | Semibold |
| Título principal editorial | Lora | Semibold |
| Título editorial secundario | Lora | Medium / Semibold |
| Texto editorial | Lora | Regular |
| Texto descriptivo | Lora | Regular |
| Énfasis editorial | Lora | Medium / Semibold |
| Números | Die Grotesk | Medium / Semibold |
| Datos / métricas | Die Grotesk | Semibold |
| Navegación | Die Grotesk | Regular / Medium |
| Botones / CTA | Die Grotesk | Medium / Semibold |
| Labels | Die Grotesk | Medium |
| Caracteres especiales | Die Grotesk | Regular / Medium |
| Texto funcional | Die Grotesk | Regular |
| Datos financieros | Die Grotesk | Medium / Semibold |

### Principio general

**Lora comunica. Die Grotesk estructura.**

Lora aporta la dimensión editorial y expresiva de Austral.

Die Grotesk aporta precisión, legibilidad y comportamiento funcional en datos e interfaces.

# 05. Paleta de colores

La identidad utiliza una paleta reducida compuesta por cuatro colores principales.

## 5.1 Celeste Bandera

- **HEX:** `#75AADB`
- **RGB:** `117 / 170 / 219`
- **CMYK:** `47 / 22 / 0 / 14`

**Uso:** Color principal del logo.

## 5.2 Deep Austral

- **HEX:** `#102A33`
- **RGB:** `16 / 42 / 51`
- **CMYK:** `69 / 18 / 0 / 80`

**Uso:**
- Fondos principales
- Textos principales
- Aplicaciones sobre fondos claros

## 5.3 Slate

- **HEX:** `#55717A`
- **RGB:** `85 / 113 / 122`
- **CMYK:** `30 / 7 / 0 / 52`

**Uso:**
- Textos secundarios
- Elementos de apoyo
- Información complementaria

## 5.4 Blanco

- **HEX:** `#FFFFFF`
- **RGB:** `255 / 255 / 255`
- **CMYK:** `0 / 0 / 0 / 0`

**Uso:**
- Fondos
- Espacios negativos
- Versiones inversas del sistema

# 06. Versiones monocromáticas

La marca dispone de diferentes versiones monocromáticas para garantizar flexibilidad de aplicación.

### Negro sobre blanco

Utilización de la marca en color oscuro sobre fondo blanco.

### Blanco sobre negro

Utilización de la marca en blanco sobre fondo oscuro.

### Escala de grises

Versión de la marca en escala de grises, utilizando aproximadamente un **70%**.

### Blanco sobre gris

Versión inversa para aplicaciones sobre fondos grises.

La versión seleccionada debe garantizar siempre un contraste suficiente entre la marca y el fondo.

---

# 07. Versión principal a color

La versión principal de la identidad utiliza:

- **Isotipo:** Celeste Bandera
- **Logotipo:** Deep Austral

Esta versión debe utilizarse preferentemente sobre **fondo blanco o fondos claros**.

---

# 08. Versión sobre fondo oscuro

Sobre fondos oscuros, especialmente **Deep Austral**, se utiliza:

- **Isotipo:** Celeste Bandera
- **Logotipo:** Blanco

Esta configuración mantiene el reconocimiento de marca y asegura contraste.

---

# 09. Usos sobre fondos

La identidad contempla cuatro escenarios principales:

### Fondo claro

Utilizar la versión principal de la marca.

### Fondo oscuro

Utilizar isotipo celeste + logotipo blanco.

### Fondo celeste

Utilizar una versión que mantenga contraste suficiente, principalmente mediante elementos blancos.

### Fotografía

La marca puede aplicarse sobre fotografía siempre que exista suficiente contraste y legibilidad.

En fondos fotográficos complejos se debe priorizar una zona visualmente limpia para la colocación de la marca.

---

# 10. Área de protección

La marca debe mantener un **área de seguridad** alrededor de su perímetro.

La unidad de medida utilizada es **X**, definida a partir de la **altura del isotipo**.

Debe respetarse una distancia mínima equivalente a **X** alrededor de la marca.

Ningún elemento gráfico, texto, imagen u otra marca debe invadir esta zona.

**Regla:**

> Área de protección = altura del isotipo (X)

---

# 11. Tamaño mínimo

La marca no debe reducirse por debajo de los tamaños establecidos, con el objetivo de preservar su legibilidad.

### Digital

**Tamaño mínimo: 32 px**

### Impresión

**Tamaño mínimo: 10 mm**

Estos valores corresponden a la marca completa y deben respetarse en aplicaciones donde sea necesario mantener la identificación y legibilidad de todos sus elementos.

---

# 12. Usos incorrectos

La identidad debe conservar siempre su construcción original.

Está prohibido:

### 01 — Deformar

No alterar las proporciones del isotipo o de la marca.

### 02 — Cambiar colores

No utilizar colores diferentes a los establecidos en el sistema.

### 03 — Rotar

No girar o inclinar la marca.

### 04 — Agregar sombras

No incorporar sombras, efectos o tratamientos no contemplados por el sistema.

### 05 — Modificar tipografía

No sustituir ni alterar la tipografía del logotipo.

### 06 — Separar elementos

No modificar arbitrariamente la relación entre isotipo y logotipo.

El sistema de identidad puede extenderse a diferentes puntos de contacto físicos y digitales.

Entre las aplicaciones contempladas se encuentran:

- Sobres

- Dispositivos móviles
- Aplicaciones digitales
- Merchandising

**Color + proporción + tipografía + área de protección + legibilidad.**

# 14. Principios visuales de Austral

A partir del sistema presentado, la identidad visual se construye alrededor de cuatro principios:

### Dirección

La flecha integrada al isotipo representa avance y orientación.

### Crecimiento

La construcción ascendente del símbolo comunica evolución y expansión.

### Futuro

La estética geométrica y tecnológica establece una conexión con innovación y proyección.

### Claridad

La combinación tipográfica establece una división funcional:

- **Lora** para comunicación, narrativa y expresión editorial.
- **Die Grotesk** para precisión, datos, números, caracteres e interfaces.

# 16. Regla maestra del sistema tipográfico

> **Lora para las palabras. Die Grotesk para los números, caracteres y lo funcional.**

La combinación de ambas familias constituye una parte central de la identidad de Austral:

**Lora = Editorial / Marca / Narrativa**

**Die Grotesk = Datos / Precisión / Tecnología / Interfaz**
